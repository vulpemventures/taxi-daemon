# liquid-taxi
🚕 Liquid Taxi backend 

## Development

### Clone

```sh
$ git clone https://github.com/vulpemventures/liquid-taxi
```

## Run

```sh
# You need to run Nigri on your machine
# nigiri start --liquid
$ make run
```

### Run test 

```sh
# You need to run Nigri on your machine
# nigiri start --liquid
$ make test
```

## Deployment 

You need the `serverless` CLI installed locally and an linked AWS account

### Staging

```sh
$ make deploy-dev
```

### Production

```sh
$ make deploy-prod
```
